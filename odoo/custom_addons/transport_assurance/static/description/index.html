Transport — Assurance

Module de gestion des polices d'assurance bus et chauffeurs pour le transport terrestre tunisien.

Fonctionnalités :

  • Polices assurance bus (RC, Tous risques, Voyage/passagers, Incendie/vol)
  • Polices assurance chauffeurs (AT/CNAM, Vie groupe, RC pro, Complémentaire santé)
  • Gestion des sinistres avec workflow complet
  • Règles légales Tunisie (RC + Voyage obligatoires, visite technique)
  • Alertes automatiques d'échéance J-30/J-15/J-7
  • Rapports : polices actives, échéancier, sinistres, bus non assurés
